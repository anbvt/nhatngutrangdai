# UI Scope and Roadmap

## MVP — Build first

| Area | MVP screens/capabilities |
|---|---|
| Public website | Home, course/program listing and detail, news/contact where existing content supports them |
| Enrollment | Guest and signed-in application form, submission confirmation, application tracking |
| Authentication | Login, registration/email verification, password recovery UI, role-aware navigation |
| Student | Dashboard, profile, applications, courses/classes, payments, schedule, attendance, exams/results, materials, notifications |
| Admin | Dashboard, student/course/class management, enrollment review, payment views, basic schedules, attendance, exams/results, materials/documents, notifications |
| Super Admin | Admin account management and privileged approval visibility |
| Shared | Vietnamese/Japanese localization, responsive design, accessibility, loading/empty/error/success states |

## Phase 2 — Operational expansion

- Advanced CRM and lead management.
- Ticket/support system with assignment and SLA.
- Expanded document workflows.
- More detailed finance and refund workflows.
- More advanced reporting and exports.
- Teacher accounts and teacher-facing tools.
- More complete CMS/content management.

## Phase 3 — Learning experience and analytics

- Learning Portfolio.
- JLPT certificate and placement history.
- Longitudinal learning progress and teacher feedback.
- Public course reviews and moderation.
- Customer journey analytics and campaign attribution.
- Advanced management dashboards and scheduled reports.

## Phase 4 — Scale and automation

- Multi-branch operations.
- Rooms, teacher availability, holidays, make-up lessons, conflict detection.
- Online exams.
- Web Push, SMS, and Zalo channels.
- Advanced marketing ROI reporting.
- More granular permissions and approval workflows.

## Explicit out-of-scope for MVP

Do not implement these as if they are ready:
- Teacher login/portal.
- Online exam-taking.
- Complex room/teacher scheduling.
- Multi-branch operations.
- Advanced CRM/lead scoring.
- Full CMS.
- Ticket/SLA support.
- Public reviews.
- Advanced marketing attribution dashboards.
- Full Learning Portfolio analytics.
