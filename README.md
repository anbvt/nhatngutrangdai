# Nhật Ngữ Trảng Dài

Responsive React prototype for course discovery, student enrollment, and student management.

## Run locally

```bash
npm install
npm run dev
```

## Prototype screens

- **Public site:** browse sample Japanese courses and submit a course consultation request.
- **Student management:** search and filter sample student records, add a record, and update course/status details.
- **Student profile:** view and edit a sample learner profile and course progress.

All student, course, schedule, and tuition information is illustrative. Changes are held in browser memory only; there is no real authentication, backend, or persistent storage.
